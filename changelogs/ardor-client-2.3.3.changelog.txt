This stable release is an optional but recommended upgrade for all users.

Bundlers UI fixes and improvements.

Support specifying the sha256 hash of the admin password in the nxt.properties
as nxt.adminPasswordHash, instead of the actual admin password.

Light client fixes and improvements.

Allow specifying JVM options and PID file location using ARDOR_JVM_OPTS and
ARDOR_PID_FILE environment variables.

Contract runner fee calculation fixes.

Added a checkpoint after the GPS hard fork, no longer accept connections from
peers version older than 2.3.2.

Node processes UI improvement - allow deleting the encrypted config file.

Performance improvements based on load testing of asset and coin exchange
transactions.

Added run-taxreport.sh and run-taxreport.bat scripts to simplify running the
tax reporting tool.

Added filter selector to list all/my standby shufflers.

Improved account ledger to distinguish fee from generated block, fee from next
blocks and fee from shuffling penalty.

Enhanced getUnconfirmedTransactions and getUnconfirmedTransactionIds APIs to
also return the transactions in the waiting pool if the request parameter
includeWaitingTransactions=true is specified.

Fixed an UI bug in setting up account control with zero maximum fees which
resulted in no fees limit being set at all. Users who have already tried
setting zero max fees should check their account control settings and if
necessary do it again.

Changelly and ChangeHero Exchange UI improvements.

Various other bugfixes and enhancements.

Updated Jetty to version 9.4.35. Old libraries in lib folder must be deleted
if installing manually.
