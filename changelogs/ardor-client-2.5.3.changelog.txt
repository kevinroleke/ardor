Now that the Nxt migration proposal has been approved by the forgers, the next
step is the launch of an Nxt child chain on the Ardor testnet. This release is
a mandatory upgrade for all Ardor testnet nodes. A testnet hardfork has been
scheduled for block 20200200, expected on Dec 15, 2025, at which the new Nxt
child chain will be activated on testnet based on a snapshot of mainnet Nxt
blockchain that was taken at block 5917500, on Nov 23, 2025.

The next Ardor release, planned for late Jan 2026, will activate the Nxt child
chain on mainnet too, based on a snapshot to be taken at Nxt block 6000000.

For testnet, 50% of the child chain Nxt has been reserved for developers
accounts, so the initial Nxt balance for each migrated account will be 50% of
its mainnet Nxt balance. Aliases and monetary system currency name ownership
have also been included in the snapshot as planned.

The JPLSnapshot add-on now also supports generating a genesis block JSON file
for an Nxt clone to satisfy the JPL 10% airdrop requirement to the Nxt child
chain token holders, for those cloning the Nxt software after the migration.

Added pagination to the open asset orders page.

Multiple improvements in the peer networking to eliminate potential deadlocks
and race conditions.

Updated Jetty to 9.4.58.
