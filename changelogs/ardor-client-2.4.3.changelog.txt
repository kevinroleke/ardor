Scheduled a hard fork for testnet at block 15660000, expected around Apr 30.
Upgrading to this release before that block is mandatory for testnet nodes.
The mainnet fork is not yet scheduled.

After the hard fork, the maximum leasing period will be increased to
32,000,000 blocks, with the default set to 150 days.

Prevent approval of phased transactions that have already finished, to take
effect after the hard fork.

Added ContractRunner support for accounts managed by a contract via the HD
wallet (BIP32) functionality.

Added a property nxt.preventLocalPeersConnection, true by default, to prevent
connection to peers found at local, loopback or link-local addresses. Set to
false when connection to local peers is needed for debugging.

Added a nxt.tools.BlacklistAllPeers tool to be able to blacklist all node
peers for debugging purposes.

Allow AddOns to declare the IDs/names of their UI plugins and allow serving
plugin content from java resources. This enables AddOns to be shipped with
their specific UI plugin(s). To achieve this, the plugin directory structure
must be created under the base resource location 'addon_plugins'. To avoid
collisions of plugin identifiers, the ID of such plugins is automatically
prefixed with "addon/" in nrs.plugins.js.

The backups created by ardor-ramdisk.sh will now be stored under the project
root instead of contrib subdirectory.

Improved fork resolution when downloading the blockchain. Peer networking
bugfixes and optimizations. Fixed bugs in database versioned tables trimming.

UI bugfixes and improvements. Disable spellcheck for password fields. Fixed
starting shuffling with private key instead of passphrase.

The lightweight contracts trigger transactions no longer rely on referenced
transactions since the use of ECBlock makes this redundant.

Updated Jetty to version 9.4.54, Bouncy Castle to version 1.77.

Updated Ledger related JS libraries.
